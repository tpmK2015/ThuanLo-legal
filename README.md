# Thuận Lộ — thông tin công khai

Mã nguồn các trang chính sách quyền riêng tư và hỗ trợ công khai cho ứng dụng Thuận Lộ. Trang được lưu trên GitHub và phục vụ bằng dự án Vercel `thuanlo-legal`.

- `index.html`: trang giới thiệu
- `privacy.html`: chính sách quyền riêng tư
- `deletion.html`: hướng dẫn và kênh yêu cầu xóa tài khoản
- `support.html`: hỗ trợ và yêu cầu về tài khoản, dữ liệu

URL công khai:

- `https://thuanlo-legal.vercel.app/deletion.html`

- `https://thuanlo-legal.vercel.app/privacy.html`
- `https://thuanlo-legal.vercel.app/support.html`

GitHub Pages của repo này đã tắt vì tài khoản GitHub kế thừa một tên miền không thuộc Thuận Lộ. Kết nối tự động giữa GitHub và Vercel chưa hoàn tất; cho đến khi sửa quyền tích hợp, triển khai thay đổi bằng Vercel CLI từ bản clone này.
